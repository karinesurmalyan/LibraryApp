## Онлайн библиотека

Веб-приложение для управления личной библиотекой. Позволяет добавлять, редактировать, удалять книги, а также искать и фильтровать их по статусу.

## Возможности

- **Добавление книг** - создание новых записей с полной информацией о книге
- **Редактирование книг** - изменение существующих данных
- **Удаление книг** - удаление записей с подтверждением
- **Поиск** - поиск книг по названию или автору
- **Фильтрация по статусу**:
  - Все книги
  - Прочитано
  - В процессе
  - Не читал
- **Хранение данных** - все книги сохраняются в localStorage

## Технологии

- **React** - библиотека для построения пользовательских интерфейсов
- **TypeScript** - типизация кода
- **Ant Design** - UI компоненты
- **React Router** - навигация между страницами

Использование

## Добавление книги

1. Нажмите кнопку "Добавить книгу"
2. Заполните форму:
   · Название книги
   · Автор
   · Статус (Прочитано/В процессе/Не читал)
   · Количество страниц
   · Рейтинг (0-10)
   · Описание
   · Заметки
3. Нажмите "Добавить"

## Редактирование книги

1. На карточке книги нажмите кнопку "Редактировать"
2. Измените нужные поля
3. Нажмите "Сохранить"

## Удаление книги

1. На карточке книги нажмите кнопку "Удалить"
2. Подтвердите удаление

## Поиск и фильтрация

· Поиск: введите название книги или автора в поле поиска
· Фильтр по статусу: выберите нужный статус из выпадающего списка

## Страница книги

· Детальная информация о книге
· Обложка книги
· Полное описание
· Заметки пользователя
· Кнопки редактирования и удаления
